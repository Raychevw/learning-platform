# Архив: модульный монолит

Здесь лежит предыдущая версия backend — единое NestJS-приложение
(Auth, Users & Groups, Course, Assignment, Grading, Webinar, Audit),
работавшее на порту 3000 без префикса `/api`.

## Почему в архиве

Проект переведён на микросервисную архитектуру (`services/*` + `api-gateway`),
под которую уже был написан фронтенд:

| | монолит (архив) | микросервисы (актуально) |
|---|---|---|
| Точка входа | `:3000`, пути `/courses`, `/assignments` | gateway `:3000`, пути `/api/*` |
| Аутентификация | mock SSO, роль из заголовка | JWT (HS256), bcrypt, RBAC |
| Данные | одна БД `lms_db` | 3 БД (course/assignment/auth) |
| События | — | Redis Pub/Sub, идемпотентный consumer |

## Статус

- не собирается и не запускается в рамках текущего проекта;
- исключён из npm workspaces и из ESLint;
- сохранён для истории и сравнения архитектурных подходов.
