# Studevo — сценарій демонстрації (5–7 хвилин)

Короткий план захисту: що відкрити, у якому порядку та що сказати. Сценарій
розрахований на живий запуск локального стеку, без Docker.

## 0. Перед демонстрацією

```powershell
cd C:\Users\lenovo\.antigravity-ide\extensions\learning-platform
.\stop-all.ps1
.\start-all.ps1
```

Перевірка, що все піднялося:

```powershell
Invoke-RestMethod http://localhost:3000/health    # status = UP
npm run verify:lab3                               # 44/44
```

Відкрити `http://localhost:5173` у двох вікнах: звичайне та режим телефона
(DevTools → Toggle device toolbar, 390×844).

тому панелі викладача й деканату не порожні.

## 1. Деканат — 1,5 хвилини

1. Увійти як `admin`.
2. **Панель**: плитки «Студенти / Групи / Борги / На перевірці», розклад,
   «Дисципліни факультету», «Успішність груп».
3. **Користувачі та групи**: нагорі — 8 студентів у трьох групах; показати
   створення групи, куратора, переведення студента, створення користувача.
4. **Відомості**: наголосити на банері «Режим перегляду» — деканат не оцінює
   роботи; показати експорт CSV.
5. **Журнал**: реальні події входу та змін.

Ключова теза: *деканат керує структурою та бачить аналітику, але не втручається
в оцінювання.*

## 2. Викладач — 2 хвилини

1. Увійти як `teacher`.
2. **Панель**: «На перевірку», дедлайни, розклад, картки курсів.
3. **Оцінювання**: обрати роботу студента, показати критерії, бали, коментар,
   підсумковий бал і ECTS. Виставити оцінку (штраф за пізню здачу
   застосовується на сервері).
4. **Мої курси → курс**: двоколонковий простір дисципліни, модулі, матеріали,
   кнопка «Додати матеріал», зовнішнє посилання на Google Meet/Zoom.
5. **Онлайн-заняття**: показати, що заняття відкриваються лише за зовнішнім
   посиланням — вбудованої WebRTC-кімнати немає.

Ключова теза: *викладач — єдина роль, яка оцінює роботи; це перевіряється і на
сервері.*

## 3. Студент — 1,5 хвилини

1. Увійти як `student`.
2. **Панель**: доступні курси, дедлайни, середній бал, розклад.
3. **Мої курси → курс**: програма, матеріали, прогрес, відмітка уроку.
4. **Завдання**: завантажити PDF/DOCX, побачити дедлайн і статус.
5. **Оцінки**: оцінка, ECTS і коментар викладача.
6. **Повідомлення**: діалог із викладачем.
7. **Мій профіль**: редагування даних і зміна пароля.

## 4. Технічна частина — 1 хвилина

1. Показати `npm run verify:lab3`: 44/44, серед них
   «Деканат не може оцінювати роботи (403)».
2. Показати термінал: gateway + 5 мікросервісів, database-per-service.
3. Показати мобільну версію: компактне меню, скрол таблиць, адаптивні форми.
4. За бажанням — Swagger: `http://localhost:3002/api/docs`.

Ключова теза: *JWT + RBAC перевіряються і в gateway, і в сервісах; оцінювання
заблоковано для деканату на рівні API.*

## 5. Якщо щось пішло не так

| Симптом | Що робити |
|---|---|
| Порожній екран | Оновити сторінку; з'явився error boundary з кнопкою перезапуску |
| 401 після входу | Перевірити `JWT_SECRET` у gateway і сервісах, перезапустити стек |
| Дані не оновлюються | `http://localhost:3000/health`, логи в `logs/` |
| Таблиця не влазить | На телефоні вона скролиться горизонтально (підказка над таблицею) |
